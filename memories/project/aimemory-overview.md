AIMemory (UI name BoltraMemory) gives Claude Code, Codex CLI, Cursor and any other MCP client one shared, local memory. Agents pull context through 27 MCP tools, write back decisions and session summaries, and link them into a graph you can browse in the 2D graph UI, the 3D galaxy or Obsidian.

Root: `~/Documents/AIMemory`. CLI: `aim`. MCP server: `aimemory`.
